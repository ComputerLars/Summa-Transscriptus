# UnifrakturMaguntia

UnifrakturMaguntia, j. «mach» wust / Peter Wiegel. [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/unifrakturmaguntia). The font is redistributed unchanged under the [SIL Open Font License 1.1](OFL.txt). Used for the masthead and short section headings; reading text remains Courier New.

## DejaVu Sans Mono

DejaVu Sans Mono is embedded in generated PDFs to retain Danish characters and the source texts’ other supported glyphs. It is redistributed unchanged under the [DejaVu / Bitstream Vera licence](DejaVu-LICENSE.txt). The screen reading continues to use Courier New where available. The freely redistributable PDF font does not depend on a reader’s installed fonts.
