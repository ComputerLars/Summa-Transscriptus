# Maskintransskriptioner og synteser fra 2023

Disse TXT-filer er kopieret uændret fra det bevarede Summa-arkiv. Filerne rummer både datidens lydgenkendelse og dens efterfølgende syntesedannelse. Stavning og fejl er derfor ikke rettet her. Den nye transskription findes separat under `disputations/`.

Filerne er organiseret i fire disputter og supplerende analysemodeller. `manifest.json` angiver originalfilernes relative stier og kontrolsummer. Filnavnenes datomærker tilhører de oprindelige genereringer.
