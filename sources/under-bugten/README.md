# Under Bugten samledokument

[Original Word-fil](manuscript.docx) · [Læs i browseren](../../manuscript.html) · [Tekst](manuscript.md).

Dokumentet samler rammetekst, manuskript, planlægningsskemaer, teser, antiteser samt ældre transskriptioner og synteser. Det er ikke ét sammenhængende referat af det sagte. Ordlyd, tabeller og indlejrede billeder er bevaret. Afsnitsnumrene i browserudgaven er redaktionelle henvisninger til denne konkrete fil; de er ikke sidetal.

Filens kontrolsum og metadata står i [source.json](source.json).
