# Fotografier fra Under Bugten

Webkopier fra det delte dokumentationsarkiv. Hele billedrammen er bevaret; orienteringen er normaliseret og størrelsen reduceret. Originalfilernes navne, links og kontrolsummer findes i [sources.json](sources.json).

- `cille-hvass-holm-1.jpg` og `cille-hvass-holm-2.jpg`: fotografier af Cille Hvass Holm. Krediteringen følger originalfilernes navne.
- `oversigtsbillede.jpg`: fotograf ikke identificeret i kildens metadata.

Fotografierne har deres egne rettigheder og omfattes ikke af programmets CC0-licens. Originalerne forbliver i [dokumentationsarkivet](https://drive.google.com/drive/folders/1k1X7lh1BW11iKi0upEbFCqDcxCJfFMsr).
