# Summa Transscriptus

Dokumentation for skolastisk komputation omkring Computer Lars-spektaklet, kurateret af Organ for de Autonome Videnskaber i en middelalderkælder under Det Jyske Kunstakademi.

**[Læs og lyt til disputationerne](https://computerlars.github.io/Summa-Transscriptus/)**

*Under Bugten* fandt sted ved Aarhus Bugt Center for Kunst på Det Jyske Kunstakademi i september 2023. Navnene følger opførelsens betegnelser. Praeses ledede disputterne.

## Manuskript og kildearbejde

- [Ramme og manuskript](https://computerlars.github.io/Summa-Transscriptus/manuscript.html): samledokumentet med rammetekst, procedure, teser, fem tabeller, syv billeder og historiske tekster. [Original Word-fil](https://computerlars.github.io/Summa-Transscriptus/sources/under-bugten/manuscript.docx).
- [Kilder og læsemåder](https://computerlars.github.io/Summa-Transscriptus/collation.html): 24 sammenholdelser af optagelser, skriftlige forlæg og konkurrerende læsninger.
- [Tvivlspunkter](https://computerlars.github.io/Summa-Transscriptus/review.html): åbne lyd- og læsesteder med tidsankre til optagelserne.
- [Transskriptioner og synteser fra 2023](https://github.com/ComputerLars/Summa-Transscriptus/tree/codex/retranscription-review/archive/2023/): 56 historiske TXT-filer, bevaret uændret.
- [Referencekilder](https://github.com/ComputerLars/Summa-Transscriptus/tree/codex/retranscription-review/documentation/references.md) · [Redaktionsprincipper](https://github.com/ComputerLars/Summa-Transscriptus/tree/codex/retranscription-review/documentation/editorial-principles.md) · [Tekstrettelser](https://github.com/ComputerLars/Summa-Transscriptus/tree/codex/retranscription-review/documentation/revisions.md).

Læseudgaverne er redigeret i oktober 2026. Læsesiden forbinder passager med lyd, forlæg, de bevarede synteser og beslægtede disputter. Den kan gentage lydudsnit, ændre afspilningshastighed og gemme lokale læsenoter til eksport. Læseudgaverne er arbejdsudgaver; åbne lydsteder er markeret. Optagelserne og de historiske synteser bevares som selvstændige kilder.
